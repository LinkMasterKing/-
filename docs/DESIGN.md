# 權益部工作看板：設計規格（DESIGN.md）

改畫面前先對照這份。使用者的要求跟這裡衝突時，先指出衝突，問要改規格還是改要求。色彩都寫在 `core/board.css` 開頭的變數，元件裡用變數、不要直接寫色碼（白色卡片、報告白紙這類「刻意不跟主題」的例外除外）。

## 整體
- 深色模式純黑底、淺色模式白底；區塊用細框（深色白框、淺色黑框）、圓角。
- 跟系統深淺色走（`prefers-color-scheme`），沒有手動切換。
- 字體：數字與英文 Jost（200–500），中文 Noto Sans TC（400／500／700）。標題字距放寬（.08–.16em）。
- 斷點：640px 以下手機；760px 頁首改排；900px 以下單欄；1000px 以上「完成紀錄」放大時用多欄。
- 版面要加安全區（`env(safe-area-inset-*)`），安裝版是全螢幕，上方有鏡頭挖孔。

## 元件規則
- **標題列**：區塊標題後接細線長箭頭（SVG mask 的弧形箭頭）。
- **時間甘特圖**：已經過去的時間（起點到今天線）整段用 `--ink` 12% 打亮（深色模式是白、淺色模式是淡灰）；今天線維持紅色；「今天」標籤白色實心黑字（細框），左上角一顆會閃的紅點（共用 `.live-dot`）。
- **時程條**（原「進度條」）：粗實線＝從開始日到今天已經過的時程（綠），細直立標記在今天的位置，灰線＝剩餘時程；兩端標開始、結束日。註記依日期放在條上（沒有期間的議題才照 %）。百分比叫「時程」（`時程 45%`），沒有期間顯示「未排程」。手動完成度已拿掉，完成改成編輯中按「結案」。
- **膠囊**：收合時全圓角；展開時高度與圓角同步變形、內容由上往下淡入；hover 白色光暈。
- **區塊外框例外**：即時回報區沒有大外框（標題列照舊，膠囊直接放在頁面上）。
- **左右兩欄**：桌面 1000px 以上、「即時回報」「進度」或「完成紀錄」被選到放大成全寬時（即時回報、完成紀錄都要先點一筆才分欄，再點一次、按「收起」或 Esc 就收回；分欄／收回時清單每一項從原位置與寬度滑到新位置，右側從右邊滑入；「進度」目前仍預設選第一筆），該區改成左側清單（約 300–380px）、右側詳情（跟著捲動停在畫面上）；點清單一列＝選取並在右側顯示，選到的列底色較亮。總覽與手機維持原本的清單＋就地展開。
  - 即時回報：左邊是白色膠囊清單（選到的加一圈外光、點了不展開），右邊是詳情面板（沒有外框，左側一條細線分隔）。檢視時唯讀；編輯中所有功能都直接在右側改，不跳視窗：名稱、說明（邊打邊存）、母議題（自製下拉）、專員（勾選）、時間標記（每列：名稱、起訖日期與時刻、期間長度、寫進母議題、刪除）、超連結（色點換色、名稱、網址、刪除）、「完成這一段」（在面板內展開兩個欄位）、結案、刪除（刪除仍會跳確認）。「+ 新增即時回報」直接新增一筆空白的並選到它。右側一欄一欄填時不重畫，焦點離開整個面板才重畫一次。
- **進度卡片**：甘特圖與議題詳情在同一張卡片，一次只看一個；甘特圖 → 詳情：原畫面往下淡出（160ms）、新畫面往上淡入（340ms），返回時同樣方式；減少動態時直接切換。詳情頁頂端「返回甘特圖」外框按鈕。處理紀錄只顯示、不放編輯鈕。
- **會議要報告**：即時回報分上下兩區，上「會議報告事項」（紅字區名＋數量）、下「其他回報」；右側詳情標題有紅框小標「報告」（`.ev-rep`）。
- **完成紀錄膠囊**：跟即時回報同一套膠囊與動畫；收合時空心綠框、綠字（`--done`），展開後跟即時回報一樣淺灰底。
- **長度變化**：區塊內容變高變矮一律用高度過渡（motion.js `flowWatch`），不可以瞬間跳。
- **議題詳情**（舊稱個別進度）：跟完成紀錄同一種清單處理，不是一張張框起來的卡片：整列滿版到區塊邊緣、每列上方一條細線、hover／展開時底色微亮（`--ink` 5%）；顏色跟著頁面（深色模式黑底），不反白；寬版多欄時欄間不留空。
- **即時回報**：膠囊一律白底黑字加細框（深淺色都一樣），狀態只放在左邊的燈號（`data-st`：ok 綠、go 黃、stall 紅）；只有紅色燈號會一直向外擴散，其他靜止。點開變淺灰底，狀態標籤用狀態色。議題卡片裡的「進行中的即時回報」小膠囊同樣白底、燈號帶狀態色。編輯中「+ 新增即時回報」排在膠囊格最後一格，大小跟一顆膠囊一樣（虛線框）。
  - 狀態以每週回報期限（`dept/config.js` 的 `week.cutoff`，預設週二）為界：期限前有更新＝綠；這週完成過一段，或期限過後才補更新＝白；期限前後都沒更新＝紅。期限過後才新增的卡片算綠。
  - 展開後依序：母議題、狀態列（狀態標籤、第幾段、最後更新）、說明、時間標記清單（左側細線＋圓點，日期／時刻／期間長度）、專員、連結、編輯工具。
- **完成紀錄**：反白區（淺色模式黑底白字、深色模式白底黑字），綠色完成燈。
- **大日期與星期幾**：星期幾（英文縮寫＋圓圈中文）置中在大日期正下方，以日期數字的字形墨跡為準（`alignDow` 量測後用 `--dow-dx` 微調），不是文字框置中。
- **頁首按鈕列**：編輯是一般外框按鈕（帶線條 icon）；每週概述是白色實心、黑字、細框（深淺色都一樣），本週週報還沒產出時左上角圓弧上冒出一顆紅點（外圈用底色描一圈，彈出動畫）：每週五起亮，直到這一週（週一到週日）有週報為止，沒產出就一直亮著；箭頭 hover 往右推。
- **底部工具列（手機）／左側細欄（桌面 900px 以上）**：毛玻璃 `.glass`（跟對話框同一套）；選取鏡片是實心膠囊（文字色），鏡片底下那一格的圖示反白（`.lit`，跟著鏡片走）；設定鍵選取時也是實心。2026-11-05 試過液態玻璃折射，同日改回這個材質。按鈕機制照 Convx（Kyant backdrop catalog），手機與桌面同一套，只差方向：
  - 分頁列：鏡片（手機 56×30、桌面 50×44，在圖示底下）。按下時鏡片放大到 78/56（主軸 .6／250、側軸 .7／250），移動時依速度沿主軸拉伸（往正方向拉長、往反方向壓扁，照原樣）。只有按在鏡片那一格才能拖，拖時位置直接跟著指標、整條列跟著偏最多 4px，放開吸到最近的分頁；點分頁＝按下 → 移過去（1／1000）→ 接近目標或 400ms 後放開。按下時整條列沿長邊放大 16px、分頁內容放大 1.2，鏡片位置有一圈白光（.5／300）。
  - 設定鍵：按下放大 4px、指標位置白光、被指標拖著微微偏移與拉伸（tanh 阻尼），放開彈回。
  - 桌面左側細欄：分頁列直立、照手機分頁列的比例（外框 6px、按鈕 50×48、寬 62 跟設定鍵一樣），設定鍵分開放在下面（間距 10px），整組垂直置中、距左 14px；只有圖示（文字只給讀屏）；沒被鏡片蓋住的圖示是次要色。內容讓出 `--rail-in`（78px），手機讓出底部 `--bar-in`（88px）。
  - 文字依背後亮度自動黑白反轉（逐元件，有遲滯），玻璃底色跟著換。工具列永遠不消失。
- **設定頁**：分組的圓角框，列與列之間細線；每列有 icon、標題、目前的值。
  - 登入前整頁只顯示一個放大的線條鎖頭（外圈細框圓形，鎖扣常駐循環開合、落下時鎖身輕震；`prefers-reduced-motion` 時不動），下面是說明與「登入」鈕；這台裝置記住了身分就直接進去。定型版（沒有密碼可登入）改顯示「這是唯讀版」。登入後沒有「需登入」標籤。
  - 桌面（900px 以上）：清單平常置中；點了有下一層的項目（編輯紀錄、身分與專員、看板資訊四項、雲端同步、分享預覽、匯出工作報告），清單往左滑成左欄（`min(440px,40%)`），右側面板滑入顯示內容，選到的列反白。再點同一列、按 Esc、或完成／取消都會收起，清單滑回置中。直接執行的動作（匯出定型版、匯出備份、匯入備份、忘記這台裝置）沒有右側面板。
  - 右側面板裡的表單是同一個 `#dlg`（加 `.in-pane`，非強制回應）：不是浮起的玻璃，標題 20px 加細分隔線。確認類（沒有欄位）與只有密碼欄的對話框一律跳出。
  - 手機維持跳出對話框。
- **毛玻璃** `.glass`（board.css「液態玻璃材質」段、util.js 的 `glassify`）：背景模糊＋內緣高光＋跟著指標移動的反光（`--mx／--my`），不用 SVG 折射。光影寫在 `--glass-sh`，要保留光影的規則（例如取消按鈕 hover 光暈時）直接引用它。
  - 2026-11-05 試過 SVG `feDisplacementMap` 折射（`glass.js`、`.lg`），使用者決定改回；程式已移除，要再做請看交接說明第二十節的做法紀錄。
- **對話框**：毛玻璃 `.glass`，開關都有動畫（關閉時用分身淡出）；下拉選單、勾選框都自製（`.csel`、`.fld-check`），不要用原生外觀。
- **分區編輯**：頁首「編輯」只負責登入與儲存／取消；看板各區標題列（細線箭頭右邊）出現一顆小外框鈕「編輯這區」（帶鉛筆 icon），按了那一區才出現編輯工具，按下狀態是實心（`--ink` 底）、文字換成「收起編輯」。一次只能改一區：按別區的「編輯這區」，原本那區自動收起；每次進入編輯都從全關開始。週報頁沒有這顆，跟著頁首「編輯」。
- **逐欄編輯（即時回報）**：即時回報沒有「編輯這區」，頁首按「編輯」後就能改。右側詳情卡與展開的膠囊都是一列一欄「標題｜內容｜小鉛筆」（名稱、說明、母議題、專員；時間標記、超連結每一筆各自一列，組下面有「+ 時間」「+ 超連結」）。按鉛筆只有那一欄變成輸入框（細框圓角小卡、淡入），下面「取消」「完成」（時間、連結多一顆「刪除」）；一次只開一欄，Enter＝完成、Esc＝取消。整筆的動作（會議要報告、完成這一段、結案、刪除）留在最下面的動作列。
- **下拉選單的清單**：底色與光影用 `--pop`／`--pop-sh`，跟著所在位置（深色頁面上的淺色詳情卡、展開的膠囊、完成紀錄裡就是淺色），文字不會跟底色撞在一起。
- **刪除鍵**：該區編輯中直接顯示在項目上（不藏在展開後），紅字；按了一定先確認。
- **按鈕**：做過視覺置中校正（不是數學置中）；非高解析螢幕用半像素陰影補圓角。

## 動態
- 一律 Web Animations；`prefers-reduced-motion` 時關掉位移動畫。
- 展開收合：像 App 開啟（高度、圓角同步）；編輯／檢視切換用 morph。
- icon：滑鼠停在上面循環播放；按一下從頭播一次、不循環。例外：設定頁登入前的鎖頭常駐循環。
- 區塊切換：手機淡出淡入；桌面 FLIP，選到的放大彈到最上面。
- 焦點：桌面沒被選到的區塊變暗（opacity .5）、略縮（scale .985），滑鼠移上去或在裡面操作時恢復；不加外框、不發光。手機即時回報展開那一下放大 3.5%、歪 -1.6° 再落平（0.64 秒），展開期間其他收著的膠囊變暗。
- 即時回報／完成紀錄的左右兩欄（1000px 以上）：清單與詳情各佔一半，清單維持格狀（即時回報通常兩欄）；詳情固定在右邊，被點的那一項彈出放大成詳情卡（位移＋clip-path，不縮放，略帶回彈），原位留虛線空位、其他項目不動；換選時舊的先縮回自己的空位再彈出新的；收起時縮回空位、那一項彈一下出現。即時回報的詳情卡跟展開的膠囊同一套外觀（淺灰底黑字、圓角 24px）。
- 編輯中拖曳排序即時回報：滑鼠拖動 6px 開始、觸控長按 0.38 秒開始；拖著的那顆放大浮起有陰影，其他 FLIP 讓位。
- 拉到底有回彈（iPhone 本來就有，不重複）；捲軸位置預留（`scrollbar-gutter: stable`），不讓版面擠壓。觸控裝置（`pointer: coarse`）所有捲動區都不顯示捲軸、也不預留位置。
- 返回：每打開一層（每週概述、設定、編輯紀錄、工作報告）就推一筆瀏覽紀錄，系統返回鍵／返回手勢先關最上面那層。
- 預測返回手勢：觸控從左邊緣（28px 內）往右拖，最上面那層跟著手指縮小（到 90%）、右移、圓角變大；放開超過寬度 28% 或甩得夠快就收掉（縮到 86%、淡出），不到就彈回。沒有任何一層時在看板上這樣拖＝回各部門總覽（編輯中不行）。每週概述本來就能左右滑，不另外加。瀏覽器自己做了返回動畫時（`hasUAVisualTransition`）直接關，不再播第二次。
- 開頁進場畫面：最上面是學生會彩色標誌（只取圖形，黃藍兩塊從左上、右下合進來）；從網站外面進來或重新整理時，全螢幕純黑（淺色白）放學生會字標（英文小字淡入、中文字距收攏、細線畫出、部門名稱浮上），至少 1.1 秒、資料與字型好了就淡出（最多 3.5 秒），收掉後才跑看板本身的進場動畫。站內換頁不放（有換頁動畫）。目前沒有學生會 logo 圖檔，先用文字字標。
- 設定頁右側面板的表單關閉時，先在原地淡出、往右滑一點（200ms）再關，面板接著收回。
- 右側會捲動的面板（即時回報、完成紀錄）裡的按鈕 hover 用貼著按鈕的小光暈，避免外散的光被邊緣切掉。
- 「編輯」鈕做過視覺置中校正：內容往上 1px、往左 1.5px。
- 跨頁（總覽 ↔ 看板）用 View Transitions：往下一層新頁從右推進；返回時舊頁縮小、右移、淡出，跟預測返回手勢同一個樣子。
- 頁首 logo（或文字 logo）＝回各部門總覽的連結。

## 工作報告（列印）
- 自訂區塊（工作檢討、下期規劃、新區塊）有段落小工具：游標所在段的左邊界（手機在區塊下方）浮出「大段／小段／內文」；段尾按＝換新段落，段中或空段按＝改這段的層級。大段（一）、小段 1.，CSS counter 自動編號，小段每個大段重算。工具本身不印出來。
- 段落縮排：每一段對齊它所屬那一層標題的文字起點，編號凸出在左邊（換行也對齊文字，不回到整份文件最左）。開頭沒有標題的內文從最左開始；大段文字起點 45px（`--rw1`），小段編號在大段文字起點、文字再往右 24px（`--rw2`）。
- 不管深淺色都是白紙黑字；A4、邊界 14mm、頁尾「第 N 頁／共 M 頁」。
- 區塊標題自動編號（一、二、三…）；空白的自訂區塊不印；按鈕列與「移除」不印。
